Desteklenen Format Kodları
  • dddd : Tam gün adı (Çarşamba)
  • ddd : Kısa gün adı (Çar)
  • DD : İki haneli gün (04)
  • D : Tek haneli gün (4)
  • MMMM : Tam ay adı (Kasım)
  • MMM : Kısa ay adı (Kas)
  • MM : İki haneli ay (11)
  • M : Tek haneli ay (11)
  • YYYY : Dört haneli yıl (2026)
  • YY : İki haneli yıl (26)
  • HH : 24 saat (00-23)
  • hh : 12 saat (01-12)
  • mm : Dakika (00-59)
  • ss : Saniye (00-59)
  • A / a : ÖÖ/ÖS veya AM/PM
  • \n : Alt satıra geç
  • [Metin] : Değiştirilmeden kalan sabit metin
